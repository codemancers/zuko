This guide walks you through running Zuko locally.

## Prerequisites

- **Node.js** 22 (matches CI)
- **Bun** (recommended package manager)
- **PostgreSQL** for the backend database

## 1. Clone the repository

```bash
git clone <repository-url> zuko
cd zuko
```

## 2. Install dependencies

From the repo root:

```bash
bun install
```

## 3. Configure environment variables

Copy the example env files and adjust as needed:

- Backend: `apps/backend/.env.example` → `apps/backend/.env`
- Web: `apps/web/.env.example` → `apps/web/.env`
- AI agents: `apps/ai-agents/.env.example` → `apps/ai-agents/.env`

Make sure to set at least:

- `DATABASE_URL` – PostgreSQL connection string for the backend
- `OPENAI_API_KEY` – API key for AI chat
- `NEXT_PUBLIC_APP_URL` and `NEXT_PUBLIC_BACKEND_URL` – app and API URLs for the web app
- `AGENT_TOKEN` – shared token used by `apps/ai-agents` to call the backend `/api/agents/*` endpoints
- `BACKEND_URL` – backend base URL for `apps/ai-agents` (example: `http://localhost:3001`)

## 4. Set up the database

Generate the Prisma client and run migrations:

```bash
bun nx run @zuko/models:prisma:generate
bun nx run @zuko/models:prisma:migrate -- --name init
```

Optionally seed test data:

```bash
bun nx run @zuko/models:seed
```

## 5. Run the app

Recommended: run the entire stack (backend, web, and agents):

```bash
bun nx run @zuko/web:dev
```

This starts the NestJS backend (for example on port 3001) and the Next.js app (for example on port 3000).

## 6. Run the AI agents service (optional)

Zuko includes a separate **ai-agents** service (`apps/ai-agents`) that hosts the LLM agent and calls the backend via `/api/agents/*`.

In a separate terminal:

```bash
npx nx run @zuko/ai-agents:dev
```

- Try the chat experience and attach CRM entities as context.
- Check out the **Concepts** and **Guides** sections for deeper dives.
